# 🍔 Food Delivery Business Analytics Dashboard

An interactive Business Intelligence dashboard built using **Power BI** to analyze the performance of a food delivery platform. The dashboard provides valuable insights into orders, revenue, customers, restaurants, delivery performance, and overall business growth.

---

## 📌 Project Overview

This project demonstrates how Power BI can transform raw food delivery data into meaningful business insights.

The dashboard helps answer questions like:

- How much revenue is generated?
- Which restaurants perform the best?
- Which cities generate the highest sales?
- How many customers place repeat orders?
- What are the monthly sales trends?
- Which delivery partners perform efficiently?
